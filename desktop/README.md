# Code Agent Desktop（Windows）

轻量 Electron 客户端：左侧项目列表 + 对话，左下角设置；打开本机文件夹后由服务端解析并问答。

## 功能

- **布局**：左侧项目与对话列表；左下角齿轮打开设置（界面主题）
- **项目**：打开本机文件夹（与 Cursor 类似）→ 服务端按该路径解析入库 → 勾选纳入对话
- **对话**：可跨多项目提问；服务端合并检索后回答
- **未选项目＝普通问答**：不勾选任何项目时，直接通用 AI 回答，并带会话上下文记忆
  （多轮追问有效）；同一会话内可随时勾选/取消项目，在「代码问答 ↔ 普通问答」
  之间来回切换，历史不断
- **本机助手**（白名单）：例如「C 盘满了」→ 扫盘分析 → 多选清理项 → 客户端安全清理
  （未选项目时仍可用，不依赖项目勾选）
- **改代码 + 编译**：补丁写回已打开的文件夹，并 `mvn compile`；失败自动读报错再修
- **启动应用**：`spring-boot:run`，识别 `Started *Application`；可 `stop_app`
- 普通对话在 Electron 下默认开启 `client_agent`（本机执行闭环）
- 黑/白主题、后端 API 地址配置

> 需桌面客户端与后端在同一台机器。本机操作仅限白名单动作（无任意命令行）。  
> **尚未支持**：Git 合并/切分支、HTTP 冒烟自测、任意系统操控——后续分阶段加。

## 使用

```bash
# 后端
conda activate business_code_agent
cd <仓库根目录>
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 客户端
cd desktop
npm start
```

1. 设置：API 地址、主题  
2. 项目：**打开文件夹** → 解析入库 → 勾选「纳入对话」  
3. 对话：代码相关请勾选项目；不勾选项目时是**普通 AI 问答**（带上下文记忆），
   磁盘清理等本机问题也可不选项目直接问；同一会话内可随时切换勾选/取消  
4. 改代码：描述需求并要求编译/启动；补丁写回本机目录 → 编译 →（若提到启动）拉起应用  
5. 清理：AI 给出选项后勾选 →「清理所选」→ 本机执行  

## 目标能力路线（客户小白场景）

| 阶段 | 能力 | 状态 |
|------|------|------|
| P0 | 问答 / 本机扫盘清理 | 已有 |
| P1 | 改代码 → 编译 → 报错修复 → 启动 | 已有 |
| P2 | Git checkout/merge/commit/push（确认卡） | 已有 |
| P3 | 通用 `run_shell` / PowerShell（必确认 + 危险命令拒绝） | 已有 |
| P4 | 对话与执行卡片同一时间线混排 | 已有 |
| P5 | 启动后 HTTP 冒烟（工具执行；是否通过由 LLM 看结果判定） | 已有 |

## 架构

```
客户端: 打开文件夹 / 对话 / 白名单执行（补丁·编译·启停·扫盘）
    │  WebSocket actions
服务端: 解析索引 → 路由 none|direct|code
        code: 出补丁 → 客户端 apply + compile (+ start)
        direct: 扫盘/启停等本机动作循环
```
